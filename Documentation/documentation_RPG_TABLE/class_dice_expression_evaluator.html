Detailed Description

A singleton MonoBehaviour that evaluates dice roll expressions in infix notation.

Handles complex dice expressions with operators (+, -, *, /, ^, d) and attribute references (@attr). Converts infix notation to postfix, evaluates rolls, and provides detailed logging. Supports features like dice rolling (2d6), math operations, and variable substitution.
